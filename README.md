# DLORG Nike Törnros

## Functions

`sort_script` creates relevant directories and moves files into their corresponding directories. Automatically runs on startup and can be manually executed.

Note: Files must be present in dlorg_nike_tornros/Downloads in order to be affected by `sort_script`

`monitor_script` watches over the creation and editing of files.

`ignore.gitignore` makes git ignore irrelevant files, such as vim's .swp files.

## Structure

- "Downloaded" files end up in 'Downloads/', simulating a downloads folder on a computer.
